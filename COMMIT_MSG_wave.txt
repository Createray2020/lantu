聚焦模式 ＋ 移除訪談檢核浮層：一份清單，住在導航裡

分組列的下拉已經在上一版改成「列面向」並帶狀態與進度，於是右下角那顆常駐
浮層做的事全部有了新家。同一件事兩個入口，就是這個 codebase 一再吃虧的
「兩個家」——所以這一版把浮層整組拆掉，而不是讓它們並存。

一、聚焦模式（甲案：標記區塊，不改 Sec 函式）
   13 個 data-ivsec 宿主掛在各段輸入區上（scope / basic / decide / params /
   income / expense / asset / debt / shortterm / coverbudget / cover /
   birth / child / planact / review）。開了「聚焦」就只展開目前這個面向，
   同分頁其餘折起來；折起來那一行的標題靠 CSS 的 attr(data-ivname) 產生，
   不在 DOM 上插節點。點一下（或 Enter/Space）可以單獨展開其中一段，
   而且不會把聚焦關掉。
   ⚠️ 折疊靠「錨點鍵比對」而不是 DOM 結構：各段沒有統一的父層
      （intentSec 的人生價值環住在 .lgwrap 裡面），照結構折會折錯。
   ⚠️ 不會折到「包含目前區塊」的外層，否則目標會跟著被藏掉。
   預設關閉——不強迫改變現役教練「直接點分頁、整頁捲」的動線。

二、移除浮層（能力一項都沒有消失）
   · 手動標記「談過但系統偵測不到」→ 上一版已先搬到下拉每一項右邊的勾
   · hint（實際的訪談題句）→ 這一版掛上面向鈕的 title，滑過去就看得到。
     它是「不會漏問」的那份 know-how，不能跟著容器一起被刪掉。
   · interviewSec() / IV_TABNAME 一併移除：「依分頁二次分群」現在由分組列做
     （navFacets / navProgress），而且是照面向的群組分，不再照分頁。
   · 浮層專用 CSS 全部清掉（.ivgrp/.ivgrphd/.ivgn/.ivbar/.ivstat/.ivlist/
     .ivrow/.ivno/.ivchk/.ivmk/.ivbody/.ivname/.ivhint/.ivgo），
     先逐一確認 class="..." 用量為 0。data-ivname 是屬性，留著。
   ⚠️ 順手修掉一個早就 commit 進來的壞掉區塊：15948–15978 有一個
      <script>，內容是浮層的抬頭註解 ＋ 一段被誤貼的 LN boot() 殘骸
      （st 未定義、還多一個 }，是語法錯誤）。瀏覽器對每個 <script> 的語法
      錯誤是各自隔離的，所以它一直沒把頁面弄壞，只是死在那裡。

三、護欄搬家（守的事情沒變，守的位置變對了）
   layoutChartsUI.test.ts 的「⑥ 訪談檢核浮層」整段失效。清單本身的護欄——
   問卷骨幹 20 題的順序、群組歸屬、面向結構完整性——搬到
   interviewUI.test.ts 的 describe("訪談檢核清單")，因為它們守的是清單而不是
   版面。留在 layoutCharts 的只有版面層級那一條：**資料區只能有一份清單**
   （分組列在、.ivgrp 為 0、.ivfab/.ivdrawer 不存在）。
   提示的斷言從「數 .ivhint 的數量」改成「每個面向都有 hint，且下拉的 title
   就是它的題句」——同一件事，換一個讀者。

2640 tests / 121 files 全綠；tsc --noEmit 與 eslint 乾淨。
