# 嵐途系統更新通知（2026/08/22）

---

## 版本一 · 完整公告（群組置頂 / Email）

**各位教練好，系統這次更新了五個地方，其中兩項跟大家日後的使用權益有關，麻煩花三分鐘看完。**

### 1. 字級可以調大了

看不清楚字、需要放大來看的人，現在頂欄右邊有一個「字級」切換，三檔：**標準／大／特大**。

- 選了之後**整個系統都會跟著放大**，包含客戶諮詢頁面、首頁、後台，不是只有某一頁。
- 設定跟著你的帳號走，換一台電腦、換一個瀏覽器登入還是一樣。
- 官網首頁沒登入時也調得動，帶客戶看試算的時候可以直接放大給他看。

面談時投影或跟客戶並排看螢幕，建議直接開「大」或「特大」。

### 2. 客戶分析頁改成「你自己決定看的順序」

分析頁原本是一長串卡片，順序固定、一次全部展開，資料多的客戶要等很久，而且每位教練習慣先看的東西並不一樣。現在改成：

- **每個分析區塊變成一張可收合的卡**，標題留著、內容收起來，要看哪一段點開哪一段。
- 最上面多了一列**模組清單**：可以直接拖曳調整順序，決定哪些先看、哪些後看。
- 不想看的模組可以按「−」隱藏，之後按「＋」再叫回來。
- 右邊有「**全部展開／全部收合／恢復預設**」三顆按鈕。

兩件重要的事：

- **順序是每位客戶各自記憶的**。你可以讓 A 客戶先看保障缺口、B 客戶先看退休需求，互不影響。
- 這是**你個人的看法設定**，不會影響客戶端看到的內容，也不會被存進客戶的規劃資料裡。

另外因為改成「點開才計算」，進入分析頁的速度會明顯變快。

### 3. 教練級別正式分成四階

| 級別 | 說明 |
| --- | --- |
| 實習教練 | 半年學習期，權限與 C1 相同 |
| 認證教練 | C1 / C2 / C3 |
| 資深教練 | S1 / S2 / S3 |
| 首席教練 | — |

**客戶資料庫上限依級別：**

| 級別 | 客戶數上限 |
| --- | --- |
| 實習教練、認證教練 C1–C3 | 20 位 |
| 資深教練 S1–S2 | 50 位 |
| 資深教練 S3、首席教練 | 100 位 |

- **封存的客戶不計入上限**。不再服務的客戶請封存（不用刪），額度就會空出來。
- 客戶列表頁的右上角會顯示你目前的額度，例如「額度 18 / 20」。

### 4. 使用期限

- 每位教練的使用期限依級別開通。**實習教練固定半年**；其他級別可以用「月」或「年」為單位設定。
- 頂欄會顯示你的**剩餘天數**，剩 30 天內會變成橘色提醒，方便提前安排續期。
- 期限到期又沒有延長時，帳號會轉成**唯讀狀態**：
  - **你的資料完全保留**，客戶、規劃、報告都還在，也都看得到、印得出來。
  - 只是不能新增或修改資料。
  - 延長期限之後**立刻恢復**，不需要重新設定任何東西。

> 目前尚未替各位開通期限，**在正式開通之前所有帳號都不受限制**。實際啟用時間與各級別的方案費用會另行通知。

### 5. 新增「學習區」

頂欄多了一個「**學習區**」分頁，是我們放教育訓練資料與線上課程影片的地方。

- 課程分成單元，可以直接在系統裡看影片、開講義。
- 每看完一個單元按「**標記完成**」，進度會留在你的帳號裡，下次進來會自動接續到還沒看完的地方。
- 課程卡片上會顯示完成率，看得出自己還差哪幾門。
- 部分課程會設定**認列訓練時數**，全部單元完成後系統會自動幫你登記，不用另外申請。

課程會陸續上架，之後有新課也會在這裡公告。
